# Локальные связи Netctl и инвентаризации

Таблица `inventory_netctl_bindings` хранит отдельное отношение сетевой
идентичности к физической карточке. Это не замена канонической
`inventory_external_bindings` для Endpoint: её ограничения один агент — одна
карточка сохраняются. Для Netctl один подтверждённый ключ принадлежит одной
карточке, а одна карточка может содержать несколько сетевых интерфейсов.

Изученный runtime-контракт создаёт `mac:<MAC>` для интерфейса. `ip:<IP>` и
`legacy-host:<row-id>` не доказывают физическую идентичность. Несогласованный,
нулевой, broadcast или multicast MAC не допускается. Коллизии источника и
совпадение с несколькими карточками блокируют подтверждение. Наблюдения
предлагают кандидатов; подтверждение требует явного сравнения и основания.

Сервис `app.inventory.netctl_bindings` не вызывает внешние команды и не
фиксирует транзакцию самостоятельно. Вызывающий обработчик обязан сохранить
решение, аудит и остальные локальные изменения одной транзакцией, с проверкой
прав, CSRF и исходной ревизии. Уникальный частичный индекс защищает ключ от
конкурентного подтверждения для двух карточек. Конфликт требует rollback.

IP и hostname — наблюдения. Обновление их значений не меняет ручную ревизию и
не переносит связь. Подтверждение/завершение меняет ревизию карточки, включая
прямые SQL-записи. Эти же защитные триггеры теперь учитывают решения Endpoint.
Отказ сохраняет историю доказательств; одна смена IP не предлагает новый
кандидат. Повторное сравнение отклонённого сопоставления должно быть явным.

Удаление карточки завершает все её связи Netctl в той же транзакции.
Восстановление сохраняет завершённую историю, не восстанавливая подтверждение.
SQLite-триггеры запрещают активную связь с удалённой карточкой. Схема создаётся
обычным `init_db`; действующие таблицы и индексы Endpoint не заменяются.
Совместимость миграций проверяется для используемого SQLite; другие СУБД
не проверены.

Текущий этап — модель и транзакционные сервисы. Подключение worker, HTTP/UI,
общей проекции, поиска/создания и фильтрации до пагинации ещё требуется для
завершения T13. Этот документ не заявляет готовность полного пользовательского
сценария. Производственные данные и сеть при проверках не изменялись.
