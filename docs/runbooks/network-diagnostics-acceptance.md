## Приёмка 12 ноября 2026 года

- VPN-сервер и управляемый узел LAN прошли замер в обоих направлениях. Скорость получателя составила 5,24 Мбит/с в каждом направлении при четырёхсекундном профиле с целевым темпом 5 Мбит/с. Точка отказала в соединении с проверенного адреса вне разрешённого списка. Вызов драйвера к неактивному локальному слушателю вернул `failed`.
- В живом PCAP 377 пакетов и 33 408 байт. `capinfos` распознал классический PCAP и длину снимка 96 байт. `tcpdump` не нашёл пакетов вне профиля. Файл, скачанный через API, совпал с локальной копией, созданной MCP. Авторизованный браузерный маршрут отдельно вернул живой PCAP и отказал в скачивании файла сервисного оператора. Срок доступа, очистку, ограничение объёма и отсутствие права скачивания проверили тестами.
- Реальный опрос охватил девять коммутаторов. На одном признаки петли отсутствовали в окне наблюдений, для восьми недостаточно данных. По всем восьми отсутствовали наблюдения STP. Положительную корреляцию, которая возвращает `suspected_loop`, проверили на фикстуре. Широковещательные счётчики в оценку не входят.
- 363 целевых теста прошли. В Playwright проверили запуск трёх форм и скачивание PCAP при ширине 390 пикселей. На развёрнутой панели проверили авторизованные HTTP-формы, скачивание, MCP, API и OpenAPI. Веб-служба и таймер Network Observer активны.
- Релиз содержит коммиты `985197a2` и `4b30ede2`.
