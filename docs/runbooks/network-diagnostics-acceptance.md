# Проверка iperf3, PCAP и признаков петель

## Перед развёртыванием

- [ ] Сверить изменения в `main`, состав развёрнутых файлов и очередность перезапусков с задачей Центра инфраструктуры.
- [ ] Проверить версии iperf3 и dumpcap, маршрут от VPN-сервера до выбранной управляемой точки, адрес источника и ограничения слушателя.
- [ ] Описать в операторском профиле источник захвата, IP и порт назначенного тестового потока. Проверить владельца и права файла конфигурации и каталога PCAP.

## Измерение пропускной способности

- [ ] Запустить отправку и приём с одного и того же утверждённого сервера. Сверить скорость отправителя и получателя, длительность, предел скорости и результат при недоступности сервера.
- [ ] Проверить, что IP, порт и пределы берутся из профиля. Запросы с произвольным адресом или параметрами команды должны отклоняться.
- [ ] Указать обе точки измерения. Отдельно записать, какой участок сети проверен и достиг ли поток ограничения скорости профиля.

## Захват для Wireshark

- [ ] Запустить захват выбранного потока и создать известный трафик в течение окна записи. Проверить, что скачанный файл читается Wireshark или capinfos и содержит пакеты только выбранного IP, протокола и порта.
- [ ] Проверить границы времени, числа пакетов и объёма. Пустой захват должен отличаться от ошибки выполнения.
- [ ] Проверить владельца, право скачивания, срок доступа и очистку. Проверить, что другой оператор и токен без права диагностики не могут получить файл.

## Признаки L2-петли

- [ ] На фикстурах проверить повторное перемещение MAC между двумя портами одного VLAN, одиночное перемещение, смену VLAN, устаревшие данные и недостаточную выборку.
- [ ] Проверить, что сочетание повторного перемещения и события STP повышает уверенность. Отдельный сигнал должен оставаться наблюдением.
- [ ] Прочитать реальные данные минимум одного коммутатора. Зафиксировать охват источников, свежесть и найденные признаки. Создание петли для проверки в рабочей сети не требуется.

## UI, API и MCP

- [ ] Проверить каталог, запуск и аудит во всех трёх интерфейсах. Для PCAP проверить скачивание через каждый интерфейс.
- [ ] Проверить доступность новых операций в OpenAPI, работу установленного MCP-скрипта и браузерный сценарий на узком экране.
- [ ] Сверить состояние панели и Network Observer после развёртывания. Зафиксировать коммиты, результаты проверок и границы наблюдения.
